# partcost — 配件成本核算模块

面向 3–5 工位独立修车厂的配件成本核算库。纯 Python + SQLite，无外部服务，
由修理厂管理系统的上层代码直接调用（无接口层），数据存一个 SQLite 文件。

## 核心规则

- 一律按**业务时间**核算；业务时间相同的按录入先后排。补录（业务时间早于
  已有事件）或作废后，该零件全部现存事件自动重算，历史成本立即更正。
- 移动加权平均：领用成本 = 结存金额 × 领用数量 ÷ 结存数量，四舍五入到分；
  领空时带走全部结存金额，保证结存数量为 0 时金额正好为 0。
- 退回按原领用成本比例回库（四舍五入到分）；原领用成本变化时退回金额随之
  重算。累计退回不超过领用数量，退回时间不早于原领用。
- 任何事件可作废（作废领用时其退回一并作废）。任何会使任一时点结存为负
  的录入/作废整笔拒绝，状态保持不变。
- 恒等式：截至任一时点，入库金额合计 = 领用成本合计 − 退回金额合计 + 结存金额。
- 工单毛利率 =（收入 − 人工成本 − 配件净成本）÷ 收入；低于 20% 为低毛利
  （正好 20% 不算，用整数交叉相乘精确判定）。

## 用法

```python
from partcost import PartCost, queries

pc = PartCost("shop.db")                       # 打开/创建 SQLite 文件
pc.upsert_work_order("WO001", "2026-01-10", 100000, 20000)  # 收入/人工（分）

pc.add_inbound("机油滤清器", 10, 1500, "2026-01-01")        # 入库 -> 事件 id
eid = pc.add_issue("机油滤清器", "WO001", 2, "2026-01-03")  # 领用
pc.add_return("机油滤清器", eid, 1, "2026-01-05")           # 退回
pc.void_event(eid)                                          # 作废

queries.balance_at(pc, "机油滤清器", "2026-01-04")          # 时点结存
queries.work_order_profit(pc, "WO001")                      # 净成本与毛利率
queries.low_margin_work_orders(pc, "2026-01-01", "2026-01-31")  # 低毛利工单
```

数量为正整数；金额一律为分（整数）；业务时间接受 `date` / `datetime` /
ISO 字符串。领用前需先 `upsert_work_order` 登记工单。

## 实现要点

- 每个事件落库时保存重算后的 `cost`、`qty_after`、`amount_after`，
  时点结存查询退化为一次索引查找，不随历史变长而变慢。
- 变更在事务内完成：插入/作废 → 按业务时间重算该零件 → 校验负库存，
  失败整体回滚。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

- `tests/test_basic.py`：计价、四舍五入、退回、作废、负库存拒绝等基础规则。
- `tests/test_scenarios.py`：补录高价入库使工单变低毛利、作废后恢复；
  非法操作被拒绝且拒绝前后查询结果不变。
- `tests/test_random.py`：随机乱序录入/补录/退回/作废，每若干步与
  “现存事件从头重算”的独立 oracle 全量对比（结存、成本、毛利、恒等式）。
- `tests/test_perf.py`：1 万条事件的零件补录 < 1s；三类查询 < 50ms。
